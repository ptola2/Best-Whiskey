## Description

_2011 characters_

```
Waterline ช่วยให้คุณเข้าใจและติดตามการอดอาหารแบบดื่มน้ำเปล่าอย่างเดียว โดยสร้างจากสิ่งที่งานวิจัยทางคลินิกระบุไว้ รวมถึงความเสี่ยงต่างๆ

รู้ว่าตอนนี้คุณอยู่ระยะไหน
• ตัวจับเวลาที่เดินอยู่ตลอดจะแสดงแต่ละระยะของเมแทบอลิซึม ตั้งแต่ไกลโคเจนเริ่มหมด ไปจนถึงเกณฑ์ 72 ชั่วโมง
• ไทม์ไลน์และการ์ด “สิ่งที่ต้องเฝ้าระวัง” จะแสดงว่าปัญหาใดมักเริ่มเกิดขึ้นในวันไหน

เช็กอินวันละ 2 ครั้ง
• บันทึกน้ำหนัก คีโตน ความดันโลหิตขณะนอนและขณะยืน ชีพจร และอาการ
• การเช็กอินแต่ละครั้งจะประเมินผลโดยเทียบกับเกณฑ์ที่ตีพิมพ์แล้ว คุณจึงเห็นได้ว่าสัญญาณใดควรใส่ใจ และสัญญาณใดหมายความว่าต้องหยุดและขอความช่วยเหลือ
• ติดตามปริมาณน้ำเปล่าที่ดื่มเทียบกับช่วง 1.2 ถึง 2.5 L ต่อวัน

ความปลอดภัยมาก่อน
• การตรวจความปลอดภัยที่สร้างจากข้อห้ามทางการแพทย์ จะระบุผู้ที่ไม่ควรอดอาหารแบบดื่มน้ำเปล่า เช่น ผู้ที่เป็นเบาหวานชนิดที่ 1 ผู้ที่ตั้งครรภ์ หรือผู้ที่มีโรคการกินผิดปกติ
• หากคุณใช้ยาหรือมีโรคประจำตัวที่ต้องให้แพทย์ดูแล แอปจะแจ้งให้ทราบก่อนที่คุณจะเริ่ม
• เช่นเดียวกับในงานวิจัย การอดอาหารที่นานกว่า 72 ชั่วโมงต้องยืนยันว่ามีแพทย์ผู้ดูแลกำกับ
• เพิ่มหมายเลขโทรศัพท์ของแพทย์ผู้ดูแลของคุณ เพื่อให้โทรหาได้ในแตะเดียวเสมอ

เลิกอดอาหารอย่างปลอดภัย
• แผนการกลับมากินอาหารที่ปรับตามระยะเวลาการอดอาหารของคุณ โดยใช้ระดับความเสี่ยงของ ASPEN และ NICE: ใช้เวลานานเท่าไร กินกี่แคลอรี แต่ละวันควรกินอะไร และต้องเฝ้าระวังอะไรบ้าง

เรียนรู้ข้อมูลทางวิทยาศาสตร์
• การเปลี่ยนแปลงทีละชั่วโมง ฮอร์โมน ผลการศึกษา ผลข้างเคียง และกลุ่มอาการรีฟีดดิง พร้อมลิงก์ไปยังแหล่งอ้างอิงทุกรายการ

ออกแบบมาเพื่อความเป็นส่วนตัว
• ไม่ต้องสร้างบัญชี ข้อมูลทุกอย่างเก็บไว้บน iPhone ของคุณ ไม่มีโฆษณาและไม่มีการติดตามผู้ใช้

ใช้งานได้ในภาษาของคุณ
• รองรับ 21 ภาษา รวมถึงภาษาอาหรับ จีน ฝรั่งเศส เยอรมัน ฮินดี ญี่ปุ่น สเปน และสวาฮีลี เปลี่ยนภาษาได้ทุกเมื่อ

สำคัญ
Waterline เป็นเครื่องมือเพื่อการศึกษา ไม่ใช่เครื่องมือแพทย์และไม่ใช่คำแนะนำทางการแพทย์ และไม่ได้วินิจฉัยหรือรักษาโรคหรือภาวะใดๆ การอดอาหารแบบดื่มน้ำเปล่าไม่ได้ปลอดภัยสำหรับทุกคน โปรดพบแพทย์ก่อนการอดอาหารทุกครั้ง และอดอาหารนานกว่า 72 ชั่วโมงภายใต้การดูแลทางการแพทย์เท่านั้น ในกรณีฉุกเฉิน โปรดโทรหมายเลขฉุกเฉินในพื้นที่ของคุณ
```
