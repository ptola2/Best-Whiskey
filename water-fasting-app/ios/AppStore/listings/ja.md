## Description

_1029 characters_

```
Waterlineは、水のみの断食を理解し、記録するためのアプリです。リスクも含め、臨床研究で示されていることをもとに作られています。

【今どの段階にいるかを知る】
• ライブタイマーが、グリコーゲンが尽きる段階から72時間の境目まで、代謝の各段階を表示します。
• タイムラインと「注意すること」カードで、どの問題がふつう何日目ごろに起こり始めるかがわかります。

【1日2回のチェックイン】
• 体重、ケトン体、横になったときと立ったときの血圧、脈拍、症状を記録します。
• 各チェックインを公表された基準値に照らして評価するので、注意が必要な兆候と、中止して助けを求めるべき兆候がわかります。
• 飲んだ普通の水の量を記録し、1日1.2〜2.5 Lの範囲と比べられます。

【安全第一】
• 医学的な禁忌にもとづく安全チェックで、1型糖尿病、妊娠中、摂食障害など、水断食が適さない人を除外します。
• 医師の判断が必要な服用薬や持病がある場合は、始める前にお知らせします。
• 研究と同じく、72時間を超える断食には、医療者による管理の確認が必要です。
• 担当医の電話番号を登録しておけば、いつでもワンタップで電話できます。

【安全に断食を終える】
• 断食の長さに合わせて、ASPENとNICEのリスク区分にもとづく回復食プランを作成します。回復食の期間、カロリー、日ごとに食べるもの、注意すべきことがわかります。

【科学的な背景を学ぶ】
• 時間ごとの変化、ホルモン、研究結果、副作用、リフィーディング症候群について、すべての出典へのリンク付きで解説します。

【プライバシーを守る設計】
• アカウント登録は不要です。データはすべてお使いのiPhoneの中にとどまります。広告もトラッキングもありません。

【あなたの言語で】
• アラビア語、中国語、フランス語、ドイツ語、ヒンディー語、日本語、スペイン語、スワヒリ語など、21言語に対応しています。いつでも切り替えられます。

【重要】
Waterlineは教育用ツールです。医療機器ではなく、医学的助言でもありません。また、いかなる病気の診断や治療も行いません。水断食は誰にとっても安全なわけではありません。どのような断食でも、始める前に必ず医師の診察を受けてください。72時間を超える断食は、医療管理下でのみ行ってください。緊急時は、お住まいの地域の緊急通報番号に電話してください。
```
